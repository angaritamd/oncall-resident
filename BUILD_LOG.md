## 2026-10-27 — Day 3 · ANG-172: draft, edit, RAD·QC and human signature (PR A)

- **Tools:**
  - `draft_report` only uses findings the radiologist dictated or confirmed; with none, it asks.
  - `edit_report` applies one exact replacement in one section, returns a word diff and never propagates the change to other sections.
  - `qc_check` runs RAD·QC.
- **RAD·QC:**
  - Two layers. Deterministic rules prove measurement and laterality conflicts ("Error demostrado", with the exact fragments and an exact proposed fix). A checker prompt written from scratch for Glimmer covers the four mechanical types ("Verificar"); quotes that are not literally in the report are discarded.
  - QC re-runs after every edit and never changes the report on its own.
  - A dismissal needs a reason, which is recorded and survives re-runs.
- **Signing:**
  - `sign_report` is **not** a model tool. Signing is an endpoint that only the "Firmar" button calls.
  - It requires the tailnet identity, the exact reviewed version and zero open alerts, and it locks the report.
  - The model's attempt to sign is rejected and logged (test).
- **UI (pantalla 04):**
  - DraftCard (ink): conflicting fragments are highlighted in crit-dk. "Dictar cambios" is marked coming soon; "Editar texto" works.
  - QcCard (white): red/amber title plus "RAD·QC", Cuerpo/Impresión boxes, "Aplicar corrección" and "Descartar con motivo".
  - SignBar: disabled with "Firma pendiente de tu revisión" while alerts are open.
  - Older report cards in the chat are read-only.
- **Seed (synthetic):** DEMO-0004 has 12 mm in the findings vs 8 mm in the impression; DEMO-0005 has crossed laterality.
- **Usage:** every model call logs its tokens and cost (official Meta Model API prices) in Actividad. Only admins see model, tokens and cost.
- **Security:**
  - CSRF guard: every API call must be same-origin, because the tailnet identity is ambient.
  - The demo report reset is admin-only and opt-in (`DEMO_RESET_ENABLED`).
- **Includes** 08d9095: PACS down and offline take precedence over the waking state.
- **Review rounds (Codex 4, CodeRabbit 17, security reviewer 9):**
  - **Signing:** it is a single atomic SQL decision (draft, exact version, QC finished for that version, no open alert); any QC run, even a re-run, blocks it until it finishes; a signed report receives no further QC writes; and it now takes two steps ("Firmar" → "Confirmar firma").
  - **QC races:** stale QC results are discarded, and QC has a total budget below the proxy timeout.
  - **Measures:** decimals stay whole and are compared with exact `Decimal` arithmetic (1,1 cm == 11 mm; 1.5 cm == 15 mm).
  - **Corrections:** a fix that cannot apply leaves its alert open; repeated impression sentences get no automatic fix.
  - **Report text:** no free text (findings, impression, dismissal reasons) is stored in Actividad; report text reaches the model delimited as data, and a cut is marked, never silent.
  - **Spend:** computed from a `usage` table with no retention; unknown tokens or cost are never shown as 0.
  - **Errors:** PACS down while building chat context returns 503.
  - **e2e:** no hard-coded identity, and the signer is masked in screenshots.
- **Tests:**
  - core: 60.
  - e2e against hack with real Glimmer: 42 passed.
    - Report flow: seeded 12 vs 8 mm → apply → sign; crossed laterality → dismiss with reason; real model: open case → draft → "El nódulo mide 12 mm" → alert → apply → sign.
    - The model cannot sign, and cross-site requests are rejected.

## 2026-10-27 — Day 3 · ANG-177: reading-station sync, level 1 (PR B)

- **OHIF Viewer (MIT)** v3.13.12, pinned by digest. Its static build is copied into the gateway image (multi-stage), with our `app-config.js`, so OHIF needs no container of its own.
- **Viewer gateway** (`demo/viewer/gateway.py`, new) on `127.0.0.1:13030`, published only by `tailscale serve --https=8443` (no Funnel). It shares a network only with Orthanc, so no neighbour can reach it with a forged identity.
  - Same `ALLOWED_USERS` rule as the app: 401 without identity, 403 for others.
  - Read-only: GET/HEAD only, anything else gets 405.
  - Adds the Orthanc credentials server-side (the browser never sees them) and strips cookies, client auth and identity headers.
  - Refuses dot segments (`..`, `%2e%2e`, `..%2f`) with 400. Before the fix, `/dicom-web/../instances` reached Orthanc's REST API.
  - DICOMweb responses are never cached (`no-store`); an upstream failure gets a controlled 502.
  - Only the app's origin may frame it (`frame-ancestors`).
  - Orthanc builds absolute WADO-RS URLs (BulkDataURI) with the public viewer origin.
- **Station page** (`/estacion`, desktop):
  - Shows OHIF in a frame, plus a 4-digit pairing code. The code is single-use, expires in 10 minutes, only links the same tailnet login, and allows 5 wrong attempts per 10 minutes.
  - The core pushes `{"study_uid"}` over SSE (UIDs validated): no PHI, no pixels. The last UID is replayed when the station reconnects, and missed events are recovered by polling.
  - The page says so when it loses the connection (stream closed, or the core forgot the station after a restart).
- **Phone:**
  - "Vincular estación" link form and "Desvincular".
  - "Ver imágenes" became "Abrir en la estación". It is disabled ("Pronto · sin estación vinculada") until a station is linked.
  - Only the case the phone actually shows (the active case) is sent to the station. "Enviado" appears only when a connected station received it.
  - An unknown station state reads "sin dato" with a retry, never "sin estación".
  - Images are never loaded on the phone.
- **Verified live:**
  - QIDO through the gateway lists 5 studies; a POST gets 405.
  - WADO-RS frames (6.9 MB), metadata and rendered images return 200.
  - OHIF renders the opened chest X-ray. e2e runs use software WebGL (SwiftShader), because headless WebGL rendered black.
- **Review round (Codex 1, CodeRabbit 17):** all addressed and answered on PR #6.
- **Tests:**
  - core: 67, including pairing, expiry, single use, same login, rate limit, UID-only push, SSE stream, and opening a case pushes its UID.
  - gateway: 12, including dot segments sent as a raw ASGI scope, `no-store`, the 502 path and the static SPA fallback.
  - e2e phone (390 px) → station (desktop): pair → open case → station loads the same Study UID, and QIDO and frames return 200 → "Abrir en la estación" → unlink. Without a station the button reads "Pronto"; the viewer's CSP and read-only behavior are also checked.
